# ToggleButton

`ToggleButton` component represents a button that can be toggled on or off.

<Links component="toggle-button" />

## Documentation

### Usage

<Demo component="toggle-button/usage" />

### Controlled

Use the `pressed` and `defaultPressed` props to toggle between controlled and uncontrolled usage. And combine it with `onPressedChange` to listen for changes to the state.

<Demo component="toggle-button/controlled-usage" />

### Appearance

Use the `appearance` prop to select between the different button appearances.

<Demo component="toggle-button/appearance-usage" />

### Icon only

When using icon only buttons please make sure to always include an `aria-label` prop for screen readers and optionally use tooltips to visually denote the button's intent.

<Demo component="toggle-button/tooltip-usage" />

### Disabled state

Set the `disabled` prop to `true` to disable buttons and prevent any interactions.

Include visible text that explains why it's disabled: a disabled button leaves the tab order, so keyboard and screen reader users can't reach a tooltip on it.

<Demo component="toggle-button/disabled-usage" />

## Accessibility

### Labels

- Give an icon only toggle button an `aria-label`. ToggleButton exposes its state with `aria-pressed`, so keep the label the same in both states.
- A disabled toggle button leaves the tab order. Explain why it's disabled in visible text nearby.
