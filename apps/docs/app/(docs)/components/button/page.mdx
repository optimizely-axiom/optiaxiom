### Different sizes

<Demo component="button/size-usage" />

### Disabled state

Set the `disabled` prop to `true` to disable buttons and prevent any interactions.

Include visible text that explains why it's disabled: a disabled button leaves the tab order, so keyboard and screen reader users can't reach a tooltip on it.

<Demo component="button/disabled-usage" />

### Icons

Use the `icon` prop to add icons to a button.

#### Left and right icons

Icons are placed to the left by default but can be placed to the right using the `iconPosition` prop.

<Demo component="button/icon-usage" />

#### Icon only button

Use the `icon` prop and omit the `children` to display an icon only button.

For accessibility please make sure to always include an `aria-label` prop for screen readers and optionally use tooltips to visually denote the button's intent.

<Demo component="button/icon-only-usage" />

### Grouping buttons

Use the `<ButtonGroup />` component to group related buttons together.

<Demo component="button/group-usage" />

### Links

#### Button as links

Set `asChild` to `true` and wrap children in an `<a>` element to render buttons as links.

<Demo component="button/link-usage" />

#### Disabled button links

Make sure to prevent interactions manually using `event.preventDefault()` since `<a>` elements do not support the `disabled` prop.

Alternatively you can use our `Link` component which supports the `disabled` prop.

<Demo component="button/link-disabled-usage" />

### Loading state

Set the `loading` prop to `true` to show a loading spinner and mark the button `aria-busy`.

Don't also set `disabled`: a disabled button loses keyboard focus mid-action. The button stays clickable while loading, so ignore repeat clicks in your `onClick` handler if the action shouldn't run twice.

<Demo component="button/loading-usage" />

## Accessibility

### Labels

- Give an icon only button an `aria-label`, since it has no visible text. Button logs a console error when the label is missing.
- A disabled button leaves the tab order, so keyboard and screen reader users can't reach a tooltip on it. Explain why it's disabled in visible text nearby.

### Loading

`loading` marks the button `aria-busy` and keeps it focusable and clickable. Ignore repeat clicks in your handler when the action shouldn't run twice.
