# AxiomProvider

`AxiomProvider` provides all the context managers required for our components to work. It must be rendered at the root of your application and should be used only once.

<Links component="axiom-provider" />

## Documentation

### Usage

```jsx
import { AxiomProvider } from "@optiaxiom/react";

export function App() {
  return <AxiomProvider>{/* Your app code here */}</AxiomProvider>;
}
```

### Locale

Use the `locale` prop to set a [BCP-47 language tag](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/Locale) used to localize date and time components such as `Calendar`, `DateRangePicker`, `Clock`, and `Time`. This controls their captions, weekday headers, week start, range text, AM/PM labels, and numbering system. When omitted, the browser locale is used.

```jsx
<AxiomProvider locale="fr-FR">{/* Your app code here */}</AxiomProvider>
```

A string leaves the text components render on their own, such as close buttons, `Pagination` labels and screen reader announcements, in English. To translate that text too, import a `Locale` and pass it instead. Each language is its own entry point, so your app only bundles the one it imports.

```jsx
import { de } from "@optiaxiom/react/locale/de";

<AxiomProvider locale={de}>{/* Your app code here */}</AxiomProvider>;
```

| Language | Import                                            |
| -------- | ------------------------------------------------- |
| English  | `import { en } from "@optiaxiom/react/locale/en"` |
| French   | `import { fr } from "@optiaxiom/react/locale/fr"` |
| German   | `import { de } from "@optiaxiom/react/locale/de"` |
| Japanese | `import { ja } from "@optiaxiom/react/locale/ja"` |
| Spanish  | `import { es } from "@optiaxiom/react/locale/es"` |

A `Locale` is a `code` used for dates and `messages` with every built-in label keyed by its English text. Spread one to format dates for a region (`{ ...de, code: "de-AT" }`), or build your own for a language Axiom doesn't ship. TypeScript checks that it has every key.

```tsx
import { AxiomProvider, type Locale } from "@optiaxiom/react";

const sv: Locale = {
  code: "sv-SE",
  messages: { "Next page": "Nästa sida" /* … */ },
};

<AxiomProvider locale={sv}>{/* Your app code here */}</AxiomProvider>;
```
