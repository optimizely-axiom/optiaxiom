# Tooltip

Popup with brief information shown when user interacts with an element using keyboard focus or mouse hover.

<Links component="tooltip" />

## Documentation

### Usage

<Demo component="tooltip/usage" />

Keep tooltip content to a short plain-text label of a few words. A tooltip closes when the pointer moves onto it and doesn't open on tap, so longer, rich or interactive help belongs in a [Popover](/components/popover/) opened from a labelled button.

Keyboard users open a tooltip by focusing its trigger, so the trigger must be focusable or contain a focusable element. Don't put information users need only in a tooltip on static content such as a card or a label.

### Controlled

Use the `open` and `defaultOpen` props to toggle between controlled and uncontrolled usage. And combine it with `onOpenChange` to listen for changes to the state.

<Demo component="tooltip/controlled-usage" />

### Placement

Use the `side` and `align` props to control where the tooltip is placed by default.

<Demo component="tooltip/placement-usage" />

### Auto

Use the `auto` prop to only show the tooltip when the underlying text is clipped.

<Demo component="tooltip/auto-usage" />

### Delay

Use the `delayDuration` prop to control how long to wait to open the tooltip after mouse hover.

## Accessibility

### Trigger and content

- The trigger must be focusable or contain a focusable element, since keyboard users open the tooltip by focusing it.
- Keep content to a short plain-text label. A tooltip doesn't open on tap and closes when the pointer moves onto it, so put longer or interactive help in a [Popover](/components/popover/).
