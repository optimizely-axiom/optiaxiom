### Modifiers

Use the `modifiers` prop to show modifier keys, as symbols on macOS and names elsewhere. `mod` shows Command (⌘) on macOS and Ctrl on other platforms, so use it for shortcuts like Cmd/Ctrl+K.

<Demo component="kbd/modifiers-usage" />
