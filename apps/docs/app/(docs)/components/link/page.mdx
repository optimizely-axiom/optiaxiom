# Link

Anchor element for creating hyperlinks.

<Links component="link" />

## Documentation

### Usage

<Demo component="link/usage" />

### Appearance

Use the `appearance` prop to select between the different link appearances.

<Demo component="link/appearance-usage" />

### Disabled links

Set the `disabled` prop to `true` to style links to appear disabled and also prevent any interactions.

<Demo component="link/disabled-usage" />

### External links

Set the `external` prop to `true` to add an icon and set the correct rel and target attributes.

<Demo component="link/external-usage" />

### Links as buttons

For an action that doesn't navigate, such as opening a dialog or a support widget, set `asChild` to `true` and wrap a `<button>` element. It looks like a link and behaves like a button.

<Demo component="link/button-usage" />
