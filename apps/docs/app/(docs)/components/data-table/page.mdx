# DataTable

Easy to use table and datagrids built using [TanStack Table](https://tanstack.com/table/latest).

<Links component="data-table" />

## Documentation

### Install

Install the required peer dependencies to start using this component:

```sh npm2yarn
npm install @tanstack/react-table
```

### Usage

Use the `table` prop to pass a table instance returned from `useReactTable()` hook. At minimum make sure to include `columns`, `data`, and `getCoreRowModel` when using the hook.

TanStack makes every accessor column sortable by default, so each header renders a sort button. Pass `enableSorting: false` unless the table [sorts](#sorting) its rows, otherwise clicking a header flips the arrow without reordering anything.

<Demo component="data-table/usage" />

### Anatomy

```tsx
import { DataTable, DataTableBody, DataTableFooter } from "@optiaxiom/react";

export default () => (
  <DataTable>
    <DataTableBody>
      <DataTableAction />
      <DataTableCheckbox />
      <DataTableLabel />
    </DataTableBody>

    <DataTableFooter />
  </DataTable>
);
```

### Vertical scrolling

Headers in `DataTable` are sticky by default. Set a height on the component to allow scrolling vertically when a large number of rows are present.

<Demo component="data-table/sticky-header-usage" />

### Column sizing

Set a column's width in pixels with the `size` column option (150 by default). Columns are resizable by default: `size` is their starting width, they share any leftover table width in proportion to their `size`, and users can drag the header edge to resize them, down to `minSize` and up to `maxSize`.

Set `enableResizing: false` on a column to keep it at exactly `size`, such as a status or action column.

<Demo component="data-table/column-sizing-usage" />

### Column pinning

Follow the [column pinning guide](https://tanstack.com/table/latest/docs/guide/column-pinning) and use the `columnPinning` option to pin columns either to the left or right side of the table.

<Demo component="data-table/sticky-column-usage" />

### Row selection

Follow the [row selection guide](https://tanstack.com/table/latest/docs/guide/row-selection) to allow selecting and highlighting rows.

Use the `DataTableCheckbox` component to automatically attach selection handlers and make the whole row selectable.

Combine `Checkbox`/`DataTableCheckbox` with `Cover` to make them easier to interact with by spanning the whole cell.

Finally, make sure to use the `DataTableLabel` in your primary cell to set the label of the row and the checkbox for screen readers.

<Demo component="data-table/row-selection-usage" />

### Row actions

Use the `DataTableAction` component to show links, buttons, or dropdown menus within rows that are only visible when the user hovers over the row.

You can enable the `primary` prop on any one of those actions to mark that as the primary action. This will automatically enable keyboard navigation within the table:

- Double click on row to perform primary action.
- Use up/down/left/right arrow keys to navigate between rows and actions.

Finally, make sure to use the `DataTableLabel` in your primary cell to set the label of the row for screen readers.

<Alert intent="warning" mt="16">
  Hover over the rows to perform more actions:

### Pagination

`DataTable` supports both client-side and server-side pagination. Follow the [pagination guide](https://tanstack.com/table/latest/docs/guide/pagination) to learn how to implement pagination with TanStack Table.

#### Client side

Simply provide the `getPaginationRowModel` and `pagination` options to use client-side pagination.

<Demo component="data-table/pagination-client-usage" />

#### Server side

To implement manual server-side pagination we can use `manualPagination` and `rowCount`. Then combine it with `onPaginationChange` and `state.pagination` to control pagination and react to changes.

<Demo component="data-table/pagination-server-usage" />

### Loading state

Set the `loading` prop to `true` to show a loading skeleton while your table data is loading.

### Empty state

Use the `empty` prop on `DataTableBody` to show content in a full-width row when the table has no rows.

<Demo component="data-table/empty-usage" />

### Sorting

`DataTable` supports both client-side and server-side sorting. Follow the [sorting guide](https://tanstack.com/table/latest/docs/guide/sorting) to learn how to implement sorting with TanStack Table.

#### Client side

Provide `getSortedRowModel` on the table to sort rows on the client. Every accessor column is sortable by default; set `enableSorting: false` on a column to opt it out.

<Alert intent="warning" mt="16">
  Hover over and click the table headers to sort by columns:
</Alert>

<Demo component="data-table/sorting-client-usage" />

#### Server side

To sort on the server, control sorting with `onSortingChange` and `state.sorting`, and pass rows in the order the server returns them. Leave out `getSortedRowModel` (or set `manualSorting`) so the table keeps that order.

<Alert intent="warning" mt="16">
  Hover over and click the table headers to sort by columns:
</Alert>

<Demo component="data-table/sorting-server-usage" />

### List view

A collection page combines a search input and filter menus above the table with a primary create action. Wire search to `globalFilter` and each menu to its column's filter value, add `getFilteredRowModel` and `getPaginationRowModel`, and TanStack resets to the first page whenever the criteria change. Put row commands in a trailing column behind one `EllipsisMenuButton`, and use `empty` to offer a way out when nothing matches.

<Demo component="data-table/list-view-usage" />

### Expanding rows <Badge intent="primary">ALPHA</Badge>

Follow the [expanding guide](https://tanstack.com/table/latest/docs/guide/expanding) to allow expanding and collapsing rows.

Use the `DataTableExpandableHeader` and `DataTableExpandableCell` components to render columns with built-in buttons for toggling rows.

Finally, combine it with the `loading` prop to show a loading state while expanded rows are being fetched.

<Demo component="data-table/expanding-rows-usage" />

### Virtualized

Table automatically uses virtualized rendering when rows and columns cross a certain threshold to improve rendering performance.

Columns will be virtualized when there are more than 20 columns in a table and rows will be virtualized when there are more than 20 rows rendered or if columns are also being virtualized.

### Labels

- Put `DataTableLabel` in each row's primary cell. It names the row and its selection checkbox for screen readers.

### Keyboard navigation

- Mark one `DataTableAction` per row as `primary` to enable arrow key navigation between rows and actions.
