# Toast

Display a brief notification.

## Documentation

### Usage

Use `toaster.create()` to add toasts. The method takes two arguments `message` and `options`.

<Demo component="toast/usage" />

### Appearance

Use the `intent` option in the second argument to select between the different toast types.

<Demo component="toast/appearance-usage" />

### Action

Use the `action` and `onAction` options to include a short action button associated with the toast.

Toasts with an action stay open 1.5 times the provider's `duration`. They still close on their own, so keep whatever the action does reachable elsewhere too. For undo, apply the change right away and make the action restore it, like the demo below.

<Demo component="toast/action-usage" />

### Dismiss

Use `toaster.remove()` to remove toasts. The `create()` method returns a unique ID for the toast which can then be passed to the `remove()` method.

<Demo component="toast/dismiss-usage" />

### When not to use a toast

A toast briefly confirms something that already happened. Use something else for:

- **Undo windows that hold a change back:** apply the change right away and make the toast action restore it, without a confirmation dialog beforehand.
- **Progress on running work:** show it on the control that started it, with `Button` `loading` or an inline `Spinner`.
- **Long or persistent messages:** use `Banner` or `Alert`.

## Accessibility

### Announcements

- Toasts are announced to screen readers when they appear. Keep the message short and self-contained.
- Keyboard users press `F8` to move focus to the toasts. The timer pauses while focus or the pointer is on a toast.
- A toast closes on its own, so keep whatever its action does reachable elsewhere too.
