# Min Height

Use `minH` prop to control the min-height of an element.

A flex item doesn't shrink below its content by default. When a scrolling list sits inside a flex column that fills a fixed-height parent, set `minH="0"` on that column so it stays within the parent and the list scrolls. `minH="auto"` restores the default.
